Rules & System Access

1. Site Access & Edit Mode:

Site access is password protected upon opening. Turn on 'Edit Mode' using password authorization to show edit controls, modify game entries, or click-to-rename players on the leaderboard.

2. Leaderboard Point-and-Click Renaming:

When Edit Mode is active, click any player name on the Leaderboard (1st click: player to change), then click another player name (2nd click: target name to take). Renaming is prevented if both players co-exist in any single game.

3. Point Allocation & Tie Breaker Rules:

Point Distribution: Points are awarded based on final group placement. 1st place receives points equal to the total player pool count for that game tier, descending by 1 point per rank down to a minimum of 1 point.

Tie Breakers: Standings are ranked primarily by Sets Won. If tied, placement is decided by total Points Won. In the event of an exact tie in both Sets Won and Points Won, players share the higher tied rank and receive equal points.
