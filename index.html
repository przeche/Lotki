Rules & System Access

1. Site Access & Edit Mode:

Site access is password protected upon opening. Turn on 'Edit Mode' using password authorization to enable full scorecard edits or click-to-rename players on the leaderboard.

2. Leaderboard Point-and-Click Renaming:

When Edit Mode is active, click any player name on the Leaderboard (1st click: player to change), then click another player name (2nd click: target name to take).

3. Full Game Editing:

Click the edit icon next to any Game title in Consolidated Games to reopen the Scorecard Editor and modify date, group ranks, or player names.

4. Yellow Highlighted Items:

Items highlighted in yellow indicate data (such as player names or ranks) that have been manually modified.
